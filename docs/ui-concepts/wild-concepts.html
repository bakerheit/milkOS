milkOS: 5 totally different ideas

Not new layouts of a desktop: five different answers to what the screen is for (pipes, scenery, sentences, a kitchen, a single task). Each is still drawable by the kernel with rectangles, rounded rects, text on the 8×16 grid, circles and alpha. Use Prev / Next or tap a thumbnail.

1 Patchbay: drawn 1:1 at 1024×768 and scaled to fit.

1. Patchbay

Unix pipes you can see and rewire

medium

Key idea

The desktop is a patch bay. Every program is a box with input and output dots, and you drag wires between them: Folder to Resize to Mail. Data visibly flows down the wires, and the same patch is shown as the one-line shell command it really is.

What is new about it

A GUI that is honest about what Linux pipes are. Nothing hidden behind a window: you build, watch and edit the thing that is happening.

Cost in a kernel-drawn UI

Boxes, dots and orthogonal wires are plain rectangles, so drawing is cheap. The real work is the plumbing: a process spawner, pipes, a typed port system (images, audio, text) and a scheduler that moves data. That plumbing is something a Linux-style OS wants anyway.

Main elements

  • Patch canvas
  • Node palette (sources, filters, sinks)
  • Typed ports + wires
  • Live data counters
  • Inspector for settings
  • Command view of the patch
  • Run / stop / save

Font note

Unifont is a good match for the node text and the command view. Wires and ports carry the look.

2 Meadow: drawn 1:1 at 1024×768 and scaled to fit.

2. Meadow

The wallpaper is the data

medium

Key idea

A calm scene that is also your dashboard. The sun's position is the time. Clouds are unread mail, the pond is free disk, the windmill spins with the CPU, the lighthouse is the network, flowers are today's events. The house opens Files, the barn opens Projects.

What is new about it

Information shown as scenery you read at a glance instead of widgets you read as text. Apps are places you walk into.

Cost in a kernel-drawn UI

A scene made of circles, rects and triangles is cheap to draw, and each scene element is just a gauge bound to one number. The cost is art: it needs good taste and a handful of states (day, dusk, night). Hit testing is simple shapes.

Main elements

  • Scene with gauges
  • Sun-arc clock
  • Buildings as launchers
  • Mail clouds, disk pond, CPU windmill
  • Event flowers
  • Hover labels
  • Day / dusk / night skies

Font note

Almost no text, so Unifont hardly matters. The labels are a hover feature.

3 Verbs: drawn 1:1 at 1024×768 and scaled to fit.

3. Verbs

No apps. You build a sentence.

easy

Key idea

The whole interface is one sentence with slots: Send [bike.png] to [Mum] by [Mail]. Pick a verb, then a thing, then a person, and a preview says exactly what will happen before you press Do it. No app windows are open; the OS borrows the right program for the job.

What is new about it

Verb-first instead of app-first. People think "send this to Mum", not "open Mail, attach, find the file".

Cost in a kernel-drawn UI

It is a form: chips, a picker grid and a preview. The cost is the verb registry (each verb says what it accepts and which program does it), which is a small table. Undo for 30 seconds needs a little bookkeeping.

Main elements

  • Sentence builder
  • Verb row
  • Thing picker (recent and nearby)
  • Person picker
  • Plain-English preview
  • Do it / Undo
  • History

Font note

The sentence at 2x Unifont looks chunky but friendly. A rounded sans would make it feel more like a product.

4 Fridge Door: drawn 1:1 at 1024×768 and scaled to fit.

4. Fridge Door

A kitchen, because it is milk

easy

Key idea

The home screen is a fridge door. App magnets, sticky-note notifications you peel off to dismiss, a photo and a shopping list held by magnets, a milk carton that is your battery, a Crisper drawer that is your files. The freezer panel shows temperature as the clock and status.

What is new about it

A fully domestic, brand-led metaphor. It makes milkOS instantly recognisable and a bit silly in the best way.

Cost in a kernel-drawn UI

Rounded rects, circles and drop shadows. Magnets and notes are just draggable cards on a background. The only fiddly parts are drag and drop and the drawer animation, which can simply snap open.

Main elements

  • Magnet app launchers
  • Sticky-note notifications
  • Photo and list magnets
  • Milk-carton battery
  • Freezer status panel
  • Crisper files drawer
  • Drag to rearrange

Font note

Unifont looks like handwriting-lite on sticky notes. A handwriting font would make the notes charming.

5 One Thing: drawn 1:1 at 1024×768 and scaled to fit.

5. One Thing

Tasks, not apps; interruptions get parked

easy

Key idea

The OS shows only the task you are doing now, with its tools open and nothing else. What is next waits in a queue. Interruptions (mail, updates, pings) are parked and held until your break instead of popping up. Done moves you to the next task.

What is new about it

The unit of the screen is a task with a timer, not a window. The desktop you could wander off to simply does not exist.

Cost in a kernel-drawn UI

A task is a name, a timer and a list of tools (apps it needs). The UI is a header, one big window and two side lists. The parking logic is a notification filter with a release time. This is the cheapest concept here.

Main elements

  • Current task header + timer
  • One main work area
  • Next queue
  • Parked tray
  • Done / Swap / Park
  • Day progress dots
  • Tool list per task

Font note

Unifont works. The big task title at 3x is the main visual.

Design notes

Most milkOS-ish: 1 Patchbay. It turns the Linux idea everyone loves (small programs joined by pipes) into something you can see and touch, and the plumbing it needs is plumbing the OS needs anyway.

Most radical: 3 Verbs. It deletes the idea of an app from the user's view. It is also the cheapest way to try something truly different: a form, a verb table and a preview.

Best for the brand: 4 Fridge Door. Nobody else will ship a milk carton as a battery meter. 2 Meadow and 5 One Thing work well as modes layered on a normal desktop (an ambient screensaver, a focus mode) rather than as the whole OS.
