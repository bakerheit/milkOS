01 Whole Milk

The macOS-style desktop

medium

Key idea

Menu bar on top, floating dock at the bottom, rounded windows with traffic-light buttons. Cream and oat tones instead of grey. The "obvious" milkOS: Mac feel, milk skin.

Cost to build in a kernel-drawn UI

Windows need rounded-corner clipping, a shadow (a few alpha rects, no blur), and a dock with hover magnify only if you want it. A real window manager and an app menu model are the work.

Main elements

  • Menu bar
  • Dock
  • Windows + title bars
  • Finder-style file browser
  • Terminal
  • Spotlight (see 03)
  • Notifications
  • Lock screen

Font note

Unifont looks fine for menus and terminals but a rounded sans (like Inter or SF) would make the labels feel Mac. Dock labels especially.

02 Pail

The tiling, Linux-style desktop

easy

Key idea

No floating windows. Every app fills a tile, a thin bar at the bottom shows workspaces, the focused tile gets a honey border. Keyboard first. Think sway/i3 in cream.

Cost to build in a kernel-drawn UI

Tiling is just rectangle maths: split, resize, redraw. No overlap means no z-order or shadows. This is the cheapest "real" shell and ideal for a hobby kernel.

Main elements

  • Status bar
  • Workspaces
  • Tiling layout engine
  • Focus border
  • Terminal
  • Keyboard shortcuts

Font note

Unifont is a perfect match: everything is a text grid. A mono font like Spleen or Terminus at 8x16 would look sharper.

03 Skim

Launcher-first shell

easy

Key idea

The desktop is almost empty: a big clock and one launcher. Hit a key, type, press Enter. Apps, files and commands in the same box. Windows come and go as full-screen or half-screen.

Cost to build in a kernel-drawn UI

A text box, a result list, and a fuzzy matcher. The expensive piece is only the app and file index, and you need that for any desktop anyway.

Main elements

  • Launcher / command bar
  • Big clock
  • App + file index
  • Quick actions
  • Minimal status
  • Full-screen app windows

Font note

Unifont works. At 2x scale the launcher input is chunky and charming. A light sans would make it feel more like Spotlight.

04 Pour

Touch-friendly tablet shell

medium

Key idea

Big rounded app tiles, a search pill, glanceable widgets, a swipe-up bar at the bottom. Everything is a thumb-size target (112px). Landscape tablet layout.

Cost to build in a kernel-drawn UI

Drawing is easy (big rounded squares). The cost is the input stack: touch events from virtio-input, gestures, momentum scroll, and an on-screen keyboard.

Main elements

  • Home grid
  • Widgets
  • Search pill
  • Gesture bar
  • On-screen keyboard
  • App switcher
  • Status bar

Font note

Unifont at 1x is too small for touch. Run it at 2x/3x or use a proper font at 20px or more.

05 Curd

Terminal-centric workspace

easy

Key idea

The shell is the desktop. Panes like tmux with a tab strip on top, a command palette on Ctrl-P to launch anything. GUI apps open as floating overlays on top of panes.

Cost to build in a kernel-drawn UI

It is mostly text cells and borders, so redraws are cheap. The palette is a list and a filter. Closest to Linux roots.

Main elements

  • Tab strip
  • Panes
  • Command palette
  • Info panes (clock, disks, jobs)
  • Overlay windows
  • Keyboard-only flow

Font note

Unifont is the right font here: the whole UI lives on the 8x16 grid.

06 Today

Widget home screen

medium

Key idea

The home screen is a glanceable dashboard of cards: calendar, next event, system health, notes, recent files. Apps are one click away from a small floating dock.

Cost to build in a kernel-drawn UI

Cards are rounded rects with text. The work is the widget model: each card needs its own small data source and redraw rule.

Main elements

  • Greeting + date
  • Card grid
  • Calendar
  • System meters
  • Notes
  • Recent files
  • Mini dock

Font note

This one wants a nicer font for the greeting and card titles. Unifont 3x headings will look blocky; try a clean sans for big text only.

07 Spaces

Mission-control style overview

hard

Key idea

One key shows every window shrunk into a grid, plus a strip of virtual desktops on top. Pick a window, or drag it to another space.

Cost to build in a kernel-drawn UI

You need each window rendered into its own offscreen buffer and then scaled down. Scaled blits and animation timing are the hard parts.

Main elements

  • Window thumbnails
  • Spaces strip
  • Offscreen window buffers
  • Scaled blit
  • Drag between spaces
  • Dim overlay

Font note

Scaled-down Unifont turns into mush. Show titles under thumbnails in a normal-size font.

08 Platinum

Classic Mac OS in milk

easy

Key idea

A love letter to System 7: dithered desktop, striped title bars, square corners, hard shadows. Cream and ink only. It looks right with chunky pixel text.

Cost to build in a kernel-drawn UI

Only rectangles, 1px borders and a dither pattern. No alpha, no rounded corners. Fastest way to get something that looks intentional.

Main elements

  • Menu bar
  • Striped title bars
  • Desktop icons
  • Trash
  • Dithered wallpaper
  • Hard drop shadows
  • Scroll bars

Font note

Unifont is already period-correct here (like Chicago). A real Chicago-style bitmap font would be the cherry on top.

Sidebar-dock desktop

medium

Key idea

GNOME / elementary style: a dark top panel, a vertical dock on the left, header-bar windows with back/forward buttons. A calmer layout for widescreen.

Cost to build in a kernel-drawn UI

Same engine as 01, plus a header-bar widget set (buttons, titles, close) and a top panel with a system tray and notification area.

Main elements

  • Top panel
  • Left dock
  • Header-bar windows
  • Notification toasts
  • Activities button
  • System tray

Font note

Unifont works. Header-bar titles in bold would want a real bold face.

10 Glass

Layered, translucent, floating

hard

Key idea

Warm gradient wallpaper, translucent panels, a floating top "island", a control centre, generous rounding. Everything floats. The prettiest and the most work.

Cost to build in a kernel-drawn UI

Heavy alpha blending of big areas every frame plus shadows. Real background blur is out of reach, so panels fake it with higher opacity. Needs dirty rects and ideally a compositor.

Main elements

  • Floating top island
  • Translucent windows
  • Control centre
  • Notification stack
  • Floating dock
  • Gradient wallpaper

Font note

This is the concept that most needs a nicer font. Unifont on soft glass looks harsh; try a rounded sans at 14 to 16px.

Design notes: what to build first

Picking one look is not the same as picking a build order. Every concept needs the same four things underneath, so those come first no matter which look wins:

  1. Framebuffer + rect/rounded-rect/text/alpha primitives with a dirty-rectangle redraw. Concepts 2, 5 and 8 are almost only this.
  2. Window manager basics: a window list, z-order, focus, drag by title bar, close. Needed by 1, 2, 7, 8, 9, 10.
  3. Input: keyboard first (every concept works with it), then a pointer, then touch (only concept 4 needs touch to feel right).
  4. Launcher + status bar as the first real shell. Concept 3's launcher drops into any of the others.

My pick: ship 08 Platinum or 02 Pail as the first shell because they are cheap and honest about Unifont, then grow toward 01 Whole Milk with 03 Skim as its launcher. Keep 10 Glass and 07 Spaces as later polish: they need offscreen window buffers and scaled blits, which is where the real cost is.
