1 Shield popover: drawn 1:1 at 1024×768 and scaled to fit.

1. Shield popover

What this app can do (read-only)

medium

When

A small button in the title bar of a sandboxed app opens a panel, like a website's lock icon.

What you see

In plain English: files it can see, files you gave it, network, sound, clipboard, other windows, and the last 24 hours of its activity. Network: change is drawn but off.

Detail

Reads the process's capability set (docs/security.md) and `audit --app `.

Build note

One popover, a list of rows and a query of the audit log. No new enforcement.

Main elements

  • Title-bar shield button
  • Capability rows
  • Activity list
  • See all activity
  • Network change (parked)

Font note

Rows are short labels and values.

3 Settings > Privacy: drawn 1:1 at 1024×768 and scaled to fit.

3. Settings > Privacy

The audit log as a readable timeline

medium

When

A Settings pane with filter chips and a timeline.

What you see

Starts with a green line: Log is intact (chain verified) and a Verify again button. Events read as sentences (peek was refused /System/Settings/passwd, You gave peek one file, bob's key was trusted).

Detail

From /proc/audit and `audit verify`. Every event type in docs/security.md maps to a sentence.

Build note

A list renderer plus a table from event name to sentence.

Main elements

  • Verified banner
  • Filter chips
  • Timeline
  • Sentence table

Font note

Dots and the line carry the look.

4 Settings > Privacy > Apps: drawn 1:1 at 1024×768 and scaled to fit.

4. Settings > Privacy > Apps

Who can do what, in one table

medium

When

A table, like Security & Privacy panes elsewhere.

What you see

One row per app: files, network, sound, clipboard. Green None is good news. Changing network access from here is parked.

Detail

Reads each installed app's grants.

Build note

A table over the capability sets.

Main elements

  • App table
  • Per-column values
  • Parked change controls

Font note

Fixed columns on the 8x16 grid.

Status

Parked, not scheduled. Nothing here needs new enforcement: it reads the capability sets and the audit log that already exist. A first buildable version could be read-only. The network-changing controls overlap other work and stay parked.
