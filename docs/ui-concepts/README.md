# milkOS UI concepts

Open `index.html` in any browser (no server, no build). Arrow keys flip through the 10 concepts, T toggles a dark page.

Each mockup is drawn 1:1 at 1024x768 with only rectangles, rounded rects, text, simple icon shapes and alpha, with text on the Unifont 8x16 grid (a browser fallback mono font stands in here). Notes per concept: key idea, build cost (easy/medium/hard), main elements, font note.

| # | Name | Direction | Cost |
|---|------|-----------|------|
| 01 | Whole Milk | macOS-style menu bar + dock | medium |
| 02 | Pail | tiling, Linux-style | easy |
| 03 | Skim | launcher-first | easy |
| 04 | Pour | touch tablet shell | medium |
| 05 | Curd | terminal-centric panes + palette | easy |
| 06 | Today | widget home screen | medium |
| 07 | Spaces | overview / virtual desktops | hard |
| 08 | Platinum | classic Mac OS in milk | easy |
| 09 | Pantry | sidebar dock + header-bar windows | medium |
| 10 | Glass | translucent floating layers | hard |

Source: `scenes.mjs` holds the drawings and notes, `build.mjs` generates `index.html` (`node docs/ui-concepts/build.mjs`). The page needs no JavaScript to flip between concepts.

## milkOS 1.0 (merged look)
`milkos-1.0.html` is the merged mockup (01 + 03 + 06 + 07 + 10), `SPEC.md` is the engineer spec. Both are generated by `node docs/ui-concepts/v1.mjs` from one token table, so they cannot drift.
