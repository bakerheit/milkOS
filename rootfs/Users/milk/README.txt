Hi, this is your home directory. In Terminal, "files list" shows what is in it and
"files help" lists everything files can do. "go Documents" takes you into a folder,
"go back" back again, "go" home, and "where" tells you where you are. Deleted things
wait in the Trash.

Everything here lives in RAM (tmpfs) for now, so it is gone when the machine
restarts. A disk-backed, snapshot-capable file system (milkfs) is planned.
