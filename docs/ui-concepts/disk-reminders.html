1. Disk Utility: Overview

What is on the disk and is it safe

medium

When

A volume list on the left, a usage bar and facts on the right, like Disk Utility on other systems.

What you see

The overview speaks about safety, not just space: Time Machine's schedule, the last scrub result in words, and a warning when backups would be unencrypted.

Detail

Anyone who wants to know the disk is healthy and backed up.

Build note

Reads /sys/fs/milkfs/info, auto and scrub. No kernel changes.

Main elements

  • Volume list
  • Usage bar
  • Facts
  • Time Machine card
  • Health card

Font note

Numbers are the headline; keep labels short.

2. Disk Utility: Snapshots and Diff

Every past state, and what changed

medium

When

A table of snapshots with a toolbar of actions.

What you see

Diff shows exactly which files were added, changed, deleted or moved between a snapshot and now, using only the changed parts of the disk, so it is instant.

Detail

Answering "what did that install change?" and recovering from a mistake.

Build note

snap, /sys/fs/milkfs/snapshots, diff, rollback, delete, clone.

Main elements

  • Snapshot table
  • Action bar
  • Diff list with A/M/D/R chips

Font note

Paths are cut with ~ in the middle of long names.

3. Disk Utility: Roll back (confirm sheet)

Destructive actions explain themselves

When

What you see

It says what will be replaced in numbers (5 changes), offers a safety snapshot first (on by default) and names the button after the verb: Roll back, not OK.

Main elements

  • Consequence line
  • Take a snapshot first
  • Cancel / verb button

Font note

Danger button text is #FFFDF8 on #B5473B, 5.26:1.

7 Disk Utility: Security: drawn 1:1 at 1024×768 and scaled to fit.

7. Disk Utility: Security

Encryption and its limits, honestly

easy

When

A status card, a change-passphrase button and a recovery key note.

What you see

Says what encryption protects and what it does not: a backup made with Send is a plain copy, in a honey warning. Lock now is drawn but disabled because the system has no lock call yet.

Detail

No false sense of safety.

Build note

Reads the volume flags; change passphrase via /sys/fs/milkfs/passwd.

Main elements

  • Encryption status
  • Change passphrase
  • Recovery key note
  • Backup warning
  • Lock (needs a call)

Font note

Body text only.

8. Disk Utility: Back up

Send a snapshot to the Mac

medium

When

A save sheet.

What you see

Pick a snapshot, optionally only what changed since an older one, and a destination on the Mac share. A honey panel says the backup is not encrypted and asks you to tick that you understand.

  • Destination
  • Plaintext warning
  • Send

Design notes

Disk Utility uses only what milkfs already exposes under /sys/fs/milkfs and the snap tool. Every destructive action goes through one confirm sheet with a Danger header, a plain consequence line, an optional safety snapshot and a button named for the verb. Reminders keeps its data in plain text files under ~/Library/Reminders and reuses the Calendar's date words. Full spec: SPEC-DISK-REMINDERS.md.
