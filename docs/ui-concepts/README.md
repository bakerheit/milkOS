# milkOS UI concepts

Open `index.html` in any browser (no server, no build). Arrow keys flip through the 10 concepts, T toggles a dark page.

Each mockup is drawn 1:1 at 1024x768 with only rectangles, rounded rects, text, simple icon shapes and alpha, with text on the Unifont 8x16 grid (a browser fallback mono font stands in here). Notes per concept: key idea, build cost (easy/medium/hard), main elements, font note.

| # | Name | Direction | Cost |
|---|------|-----------|------|
| 01 | Whole Milk | macOS-style menu bar + dock | medium |
| 02 | Pail | tiling, Linux-style | easy |
| 03 | Skim | launcher-first | easy |
| 04 | Pour | touch tablet shell | medium |
| 05 | Curd | terminal-centric panes + palette | easy |
| 06 | Today | widget home screen | medium |
| 07 | Spaces | overview / virtual desktops | hard |
| 08 | Platinum | classic Mac OS in milk | easy |
| 09 | Pantry | sidebar dock + header-bar windows | medium |
| 10 | Glass | translucent floating layers | hard |

Source: `scenes.mjs` holds the drawings and notes, `build.mjs` generates `index.html` (`node docs/ui-concepts/build.mjs`). The page needs no JavaScript to flip between concepts.

## milkOS 1.0 (merged look)
`milkos-1.0.html` is the merged mockup (01 + 03 + 06 + 07 + 10), `SPEC.md` is the engineer spec. Both are generated by `node docs/ui-concepts/v1.mjs` from one token table, so they cannot drift.

## New concepts (A to D)
`new-concepts.html` has four new-paradigm concepts (Rewind, Canvas, Scroll, Dial). Source: `new-concepts.mjs` (`node docs/ui-concepts/new-concepts.mjs`).

## Five more ideas
`wild-concepts.html`: Patchbay, Meadow, Verbs, Fridge Door, One Thing. Source `wild-concepts.mjs` (`node docs/ui-concepts/wild-concepts.mjs`).

## Familiar plus one new thing
`familiar-plus.html`: five add-ons on the 1.0 desktop (Tabs everywhere, Projects, Time slider, Shelf and clipboard, Live capsule). Source `familiar-plus.mjs`.

## Notification drawers
`notifications.html`: five notification drawer concepts on the 1.0 desktop with the Tabs-everywhere window. Source `notifications.mjs`.

## Chosen notification drawer
`drawer.html` shows the side drawer through its states. Numbers are in SPEC.md under "Notification drawer". Source `drawer.mjs`.

## Review and new designs (October 2026)
`REVIEW.md` is a prioritised review of the shipped screens against the spec. `share.html` is the Milk Drop sheet (Files > Share, send, incoming, key changed). `shield.html` is a read-only app-permissions design, parked and not scheduled. Source: `share.mjs`. New SPEC sections: Buttons, Files window, Menu bar status area, Milk Drop sheet, Shield.

`REVIEW-DRAWER-TABS.md` reviews the notification drawer and window tabs builds against the spec.

`dock-alternatives.html`: six alternatives to the dock (left rail, taskbar, apps in the menu bar, auto-hide with previews, dots pill, corner fan), with the screen space each costs. Source `dock-alternatives.mjs`.

`dock-alternatives-2.html`: six more dock ideas that are not an icon strip at an edge (Rooms, Recents strip, Edge slots, Keypad, Trays, Selection-aware dock). Source `dock-alternatives-2.mjs`.

## Art direction
`ART.md` is the art direction for icons, wallpapers, the boot splash and sounds. `art-direction.html` is the visual reference, `art/check-wallpaper.py` checks a wallpaper against the glass-contrast rule. Source: `art-direction.mjs`.

## Built-in apps
`SPEC-APPS.md` specifies Activity Monitor, Text Editor, Calendar, Clock/Timer and Preview, built only on what the system can do today. `apps.html` has the 17 mockups. Source: `apps.mjs`.

`SPEC-DISK-REMINDERS.md` specifies Disk Utility (a GUI over milkfs: snapshots and diff, clones, scrub, encryption, erasing and formatting a spare disk, encrypting in place, backups and restore with passphrases, a shared confirm sheet) and Reminders (lists, due dates, repeat, rung by the alarm daemon). `disk-reminders.html` has the 18 mockups. Source: `disk-reminders.mjs`.

`SPEC-FONT-ROLLOUT.md` is the rule for one font in every app (the system font for all UI text, Unifont only for monospace content) and the per-app list of what changes. Written after the 2026-10-23 review of main.
