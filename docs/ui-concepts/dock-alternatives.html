1 Left rail: drawn 1:1 at 1024×768 and scaled to fit.

1. Left rail

A slim vertical dock down the left edge

easy

When

Familiar from GNOME, elementary and Linux desktops: icons in a column, a dot beside the running ones, a label on hover.

What you see

On a 4:3 screen vertical space is the tight one, so the rail trades a little width for 76 more pixels of window height. Skim's milk drop sits at the top, Downloads and Trash at the bottom.

Detail

Anyone who works in tall windows (the terminal, documents).

Build note

The dock code with a rotated layout and a tooltip on the right. Easiest of the six, and it is just Settings > Dock > Position: Left.

Main elements

  • Glass rail (56 wide)
  • Skim button
  • Pinned apps
  • Running dots
  • Downloads and Trash
  • Hover label

Font note

Labels only appear on hover, so Unifont is no problem.

2 Taskbar: drawn 1:1 at 1024×768 and scaled to fit.

2. Taskbar

A bottom bar with windows as labelled buttons

medium

When

The Windows layout everyone knows: launcher at the left, pinned apps, then one labelled button per window, tray at the right.

What you see

With Tabs everywhere, a tab group is one button with a small count badge instead of one button per window. Spaces are a mini switcher at the right edge.

Detail

People who juggle many windows and want to read their titles. It is the best answer to the question "what is open?".

Build note

A row layout and a window list. The extra work is truncating titles and the tab-group badge.

Main elements

  • Skim button
  • Pinned apps
  • Window buttons
  • Tab-group badge
  • Spaces switcher
  • Focused window outline

Font note

Window titles are cut at about 13 characters in Unifont.

3 Apps in the menu bar: drawn 1:1 at 1024×768 and scaled to fit.

3. Apps in the menu bar

No dock at all

easy

When

The menu bar stays as it is. The running apps sit in it as small icons, like the tray icons people already use.

What you see

The whole bottom of the screen is windows. Click an icon to focus, hover for the window list, Cmd-1 to Cmd-9 jump. The rest lives in Skim.

Detail

Small screens and people who barely use a mouse for launching.

Build note

A strip of 16px icons in the bar. Needs an overflow when more than about six apps are open.

Main elements

  • App strip in the menu bar
  • Skim button
  • Running dots
  • Hover list
  • Overflow (+ 4 more)

Font note

Icons only, so no font issue. Tooltips use Unifont.

4 Auto-hide with previews: drawn 1:1 at 1024×768 and scaled to fit.

4. Auto-hide with previews

The dock appears at the edge, with window previews

medium

When

The macOS dock, set to hide, with a thin line where it lives.

What you see

Hover an app and a card shows a small preview of each of its windows to click. It answers "which Files window?" without opening Spaces.

Detail

Anyone who wants the dock's look with the whole screen free.

Build note

Previews are scaled blits of each window's own buffer, which the compositor already has. The hover card is a glass panel.

Main elements

  • Thin edge line
  • Reveal on hover
  • Per-app preview card
  • Click to focus
  • Middle-click to close

Font note

Previews are scaled pictures; only the card titles are text.

5 Dots pill: drawn 1:1 at 1024×768 and scaled to fit.

5. Dots pill

A tiny pill with only what is running

easy

When

A floating pill like the dock, only smaller.

What you see

It shows the three or four apps you are using and a count of their windows. Everything else is one keystroke away in Skim, which is the point of the pill.

Detail

People who already open apps by typing, and anyone who finds a big dock noisy.

Build note

A small glass panel with a short list. The smallest amount of UI of the six.

Main elements

  • Glass pill
  • Skim button
  • Running apps with counts
  • Overflow menu
  • Hover label

Font note

Almost no text.

6 Corner fan: drawn 1:1 at 1024×768 and scaled to fit.

6. Corner fan

One button in the corner that fans out the apps

medium

When

A floating launcher button, like on tablets and some Android skins.

What you see

Press the milk drop and the apps fan out along an arc with labels and a ring on the running ones. Flick toward an app. It works with a thumb, a mouse or a game controller.

Detail

Touch and controller use, and a clean screen the rest of the time.

Build note

Places icons on a quarter circle and picks by angle. A little animation helps but is not needed.

Main elements

  • Corner button
  • Arc of apps
  • Labels
  • Running badges
  • Flick to choose

Font note

Labels are drawn on dark chips so they read on any wallpaper.

Design notes

Space used: today's dock takes 76px of the 768px height (10%). Left rail 64px of 1024 width (5%). Taskbar 36px (5%). Apps in the menu bar 0px. Auto-hide 4px. Dots pill 34px. Corner fan 0px when closed.

My suggestion: keep the dock as the default and add two switches in Settings > Dock: Position (Bottom or Left, the rail) and Auto-hide (with window previews, since the compositor already holds each window's buffer). The taskbar is the right extra mode for people coming from other desktops, the dots pill and the menu-bar strip suit minimal setups, and the corner fan is the one to build only if touch or a controller becomes a target.
