A Rewind: drawn 1:1 at 1024×768 and scaled to fit.

A. Rewind

The whole computer has a timeline

hard

Key idea

There is no "save" or "undo" anxiety: the OS keeps a timeline of your work (which windows were open, which files existed, what they said). Scrub back to 9:12 this morning, see the screen as it was, and either restore that moment or drag one window or file out of it.

What is new about it

Time Machine meets a journaling filesystem, but front and centre as the main way to navigate, not a backup app.

Cost in a kernel-drawn UI

The real cost is underneath: copy-on-write or journaled files, plus an event log of window layouts. The first version needs no pixels at all: store file versions and window lists, and draw the past as simple window shapes. Capturing screenshots of old moments can come much later.

Main elements

  • Timeline scrubber
  • Moments list (auto-named)
  • Past-state viewer
  • Restore / pull-out actions
  • File version store
  • Window layout log
  • Search your past

Font note

Unifont is fine. The activity colours and the playhead carry most of the look, so this one is mostly rectangles.

B Canvas: drawn 1:1 at 1024×768 and scaled to fit.

B. Canvas

One endless surface, zoom instead of switching windows

hard

Key idea

No desktops, no window switcher. Everything lives on one big surface. Zoom out and windows collapse into named cards grouped by project; zoom in and a card becomes a real window. Related things sit near each other with a line between them.

What is new about it

Semantic zoom: what you see changes meaning as you zoom, so "where is my school work" is a place, not a search.

Cost in a kernel-drawn UI

Needs a world-to-screen transform, hit testing in world coordinates, and scaled drawing of windows. To keep it kernel-friendly, use three fixed zoom levels (far: labels only, mid: cards, near: real windows) so text is only ever drawn at 1x, 2x or 4x and never shrunk.

Main elements

  • Infinite surface + dot grid
  • Cluster labels
  • Cards that become windows
  • Connector lines
  • Zoom control
  • Minimap
  • Pan by drag or keys

Font note

Never shrink the Unifont bitmap. Far-zoom labels are drawn at 2x or 4x, which is on-brand and crisp. This is the concept that suits a bitmap font best.

C Scroll: drawn 1:1 at 1024×768 and scaled to fit.

C. Scroll

A notebook shell where every command leaves a live card

medium

Key idea

The terminal's output is not text, it is a card. ls shows thumbnails, disk shows bars, edit opens an editor inline, play shows a player. Cards stay in the notebook, can be re-run, and can be pinned to a rail where they keep updating.

What is new about it

A shell and a dashboard in one. Linux soul (everything is a command) with a UI that is allowed to show pictures, bars and controls.

Cost in a kernel-drawn UI

No window manager needed, which makes it the cheapest of the four. You need a cell list, a handful of output renderers (text, table, image grid, bar, player) and a pin rail. Start with text-only cells and add renderers one at a time.

Main elements

  • Notebook of cells
  • Rich output cards
  • Prompt with completions
  • Pinned live rail
  • Re-run / reorder cells
  • Command palette

Font note

Unifont is a natural fit. A bold face would help the cell titles; the rest works as is.

D Dial: drawn 1:1 at 1024×768 and scaled to fit.

D. Dial

Modes reshape the OS; radial menus for everything

medium

Key idea

You tell the OS what you are doing (Study, Build, Play, Rest, Out) and it rearranges: which apps lead, which notifications get through, the accent colour, the wallpaper. Context actions are radial: press and hold on anything and flick toward an action.

What is new about it

Purpose first instead of app first, plus one menu style that works with mouse, touch, gamepad or number keys.

Cost in a kernel-drawn UI

A mode is just a named record (app list, notification filter, theme), so the logic is small. Radial menus need a circle drawn with rounded rects and an angle lookup (atan2 or a small table) for flick direction. Touch is optional.

Main elements

  • Mode dial
  • Mode home cards
  • Held-notifications queue
  • Radial context menu
  • Per-mode themes
  • Number-key shortcuts

Font note

The big mode name and the radial labels want a nicer font. Unifont at 3x for the title is acceptable but blocky.

Design notes

Cheapest to try first: C Scroll. It needs no window manager, it is very Linux, and the rich cards are small renderers you can add one at a time. It could even live as the terminal app inside the 1.0 desktop.

Most distinctive: A Rewind. Nothing else has "the whole computer has a timeline" as its front door. Start with file versions and window lists only, and treat screenshots of the past as a later upgrade.

B Canvas suits a bitmap font surprisingly well (labels at 2x and 4x, never shrunk). D Dial is the lightest to build but works best layered on top of another look (the modes and radial menus can sit on the 1.0 desktop).
