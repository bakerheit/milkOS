Desktop

from 01 + 10

Menu bar, dock and toast are glass over the wallpaper (pre-blurred copy). Windows are opaque with 12px corners and stacked-rect shadows. Focused window has coloured lights, the other greys out.

Home (Today)

from 06 + 10

No windows open: the wallpaper becomes a glanceable home. Cards are the same glass panels. Same dock, so the shell never changes shape.

Launcher

from 03

One key, type, Enter. Dims what is behind by 25%. Results show apps, files and commands in one list.

Spaces

from 07

Scaled blits of each window's offscreen buffer (needs the per-window buffers), plus a strip of virtual desktops. Focused window gets a 4px honey border.

Control centre

from 10

Quick settings panel from the menu bar. Glass again, so it costs one more pre-blurred-wallpaper sample, no live blur.
