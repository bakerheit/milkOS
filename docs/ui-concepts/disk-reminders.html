1. Disk Utility: Overview

What is on the disk and is it safe

medium

When

A volume list on the left, a usage bar and facts on the right, like Disk Utility on other systems.

What you see

The overview speaks about safety, not just space: Time Machine's schedule, the last scrub result in words, and a warning when backups would be unencrypted.

Detail

Anyone who wants to know the disk is healthy and backed up.

Build note

Reads /System/Kernel/fs/milkfs/info, auto and scrub. No kernel changes.

Main elements

  • Volume list
  • Usage bar
  • Facts
  • Time Machine card
  • Health card

Font note

Numbers are the headline; keep labels short.

2. Disk Utility: Snapshots and Diff

Every past state, and what changed

medium

When

A table of snapshots with a toolbar of actions.

Answering "what did that install change?" and recovering from a mistake.

Main elements

  • Snapshot table
  • Action bar
  • Diff list with A/M/D/R chips

Font note

Paths are cut with ~ in the middle of long names.

3. Disk Utility: Roll back (confirm sheet)

Destructive actions explain themselves

easy

When

A confirmation sheet with a red header.

What you see

It says what will be replaced in numbers (5 changes), says how many newer snapshots go too (a rollback deletes them) and to Send first, and names the button after the verb: Roll back, not OK.

Detail

Making a scary action safe.

Build note

One sheet pattern reused by Roll back, Delete, Discard, Keep and Repair.

Main elements

  • Red header
  • Consequence line
  • Newer snapshots go too
  • Cancel / verb button

Font note

Danger button text is #FFFDF8 on #B5473B, 5.26:1.

7. Disk Utility: Security

Encryption and its limits, honestly

easy

When

A status card, a change-passphrase button and a recovery key note.

What you see

Says what encryption protects and what it does not: a backup made with Send is a plain copy, in a honey warning. Lock now is drawn but disabled because the system has no lock call yet.

Detail

No false sense of safety.

Main elements

  • Recovery key note
  • Backup warning
  • Lock (needs a call)

8 Disk Utility: Back up: drawn 1:1 at 1024×768 and scaled to fit.

8. Disk Utility: Back up

Encrypted by default, with a passphrase

medium

When

A save sheet.

What you see

A backup from an encrypted volume is encrypted by default: pick a snapshot, optionally only what changed since an older one, a destination on the Mac share, and a passphrase typed twice. A line says there is no recovery key for a backup.

Detail

Backups that people actually understand and can not leak by accident.

Build note

snap send SNAP [--from OLDER] -o FILE, with the passphrase; receive is the matching Restore sheet.

Main elements

  • Snapshot pickers
  • Destination
  • Protection: Encrypted / Not encrypted
  • Passphrase twice
  • Send

Font note

Fields are 28 px.

10. Disk Utility: Restore

A passphrase, only if the backup needs one

easy

When

An open sheet.

What you see

The passphrase field is optional. If the backup is encrypted and it is missing or wrong, the field gets a Danger border and the sheet says so in words, and nothing is restored.

A button, and a progress row that survives a restart

medium

When

A progress card.

On a plain volume the Security tab offers Encrypt this volume.... While it runs the card shows a progress bar, blocks done and the phase in words, the button is off, and the sidebar row says encrypting 24%. It carries on by itself after a restart.

Design notes

Disk Utility uses only what milkfs already exposes under /System/Kernel/fs/milkfs and the snap tool. Every destructive action goes through one confirm sheet with a Danger header, a plain consequence line, an optional safety snapshot and a button named for the verb. Reminders keeps its data in plain text files under ~/Library/Reminders and reuses the Calendar's date words. Full spec: SPEC-DISK-REMINDERS.md.
